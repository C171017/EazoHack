# 十小时范围、演示与验收

这是未来获准实现后的工程提案，本轮只更新文档。高亮输入和四路辅助已确认；路由准则、执行触发、每路深度、模型及来源查找范围待决。假设一位熟悉 React 的开发者、可用服务账号/网络、一份排版简单的短书，本机桌面演示。

## 产品范围与建议演示深度

已确认核心：阅读 → 高亮 → 路由到一种或多种辅助 → 探索 → 保存到段落/地图。四路是交互 UI、生成图片、SVG/概念图/思维导图、来源查找；整书网络和缩小后的活动/空间书签愿景保留。高亮不是可删减增量。

建议十小时做“四路窄场景 + 至少一次组合”，而非四路任意主题都可靠：

| 部分 | 建议可交付的演示深度 | 未批准/未验证边界 |
| --- | --- | --- |
| 阅读与地图 | 一份可完整处理的短 PDF，约 15–30 概念；能选择、高亮、保存和回访段落 | 文件规模以提取量和实测预算确定；不承诺任意长书 |
| 交互 UI | 一种经过验证的教学模型，LLM 实时生成界面配置/解释并可操作、保存状态 | 完全竞争/寡头/垄断是用户例子，不能因选一个演示就声称全覆盖；自由代码生成待定 |
| 图片 | 一段选文生成一张真实图片，预览与保存 | API/账号和延迟需预检，不能拿静态占位图冒充生成 |
| 概念图 | 从选文生成小型关系图，可查看概念和联系 | 不要求自由编辑或复杂布局 |
| 来源查找 | 暂提议书内检索并返回可核对的段落 | D09 未确认；若选择外部需重新预算搜索与核验，不能静默代替 |
| 组合与回访 | 同一高亮路由到两种辅助，独立状态/保存；缩小后从书签或活动区域返回 | 组合上限与并发方式待定 |

建议输入先限有文字层、单栏简单 PDF；TXT、复杂排版与更多文件格式为后续。截图和周期采集已确定在 MVP 外。3D、云同步和任意领域模拟不是本计划默认，但相关产品/实现决定仍在登记中。

## 10 小时分配（建议）

| 时间 | 工作 | 出口条件 / 处理 |
| --- | --- | --- |
| 0:00–0:30 | 定 D06/D09/D05、示例书、调用预算和演示状态表 | 确定每路窄范围与启动方式；来源范围未定就不接外部服务 |
| 0:30–1:30 | 阅读器、选文/高亮/锚点、服务接入预检 | 重复选文、跨行选择、刷新恢复可用；各服务权限有证据。失败优先换简单 PDF，高亮不能改成节点入口 |
| 1:30–2:30 | 整书分块、覆盖清单、简单网络 | 完整覆盖或标明部分；必要时演示预生成地图并明示 |
| 2:30–3:15 | 路由计划、单路/组合任务、上下文快照 | 同一选文能选择一条或多条；更换选区不串结果 |
| 3:15–4:30 | 窄主题实时生成交互 UI | 参数操作有真实可解释行为，显示假设；验证模型边界 |
| 4:30–5:15 | 选文生成概念图 | 图形可读、关系可核对，关联选文 |
| 5:15–6:00 | 图片生成/保存 | 真正服务返回的图片可重开；错误可见 |
| 6:00–6:45 | 来源查找 | 按已决定范围返回可核对来源，空结果不编造 |
| 6:45–7:45 | 多产物保存、地图关联、书签/简易活动层 | 刷新恢复，组合部分失败仍保留其他产物 |
| 7:45–9:00 | 全流程验收与修复 | 高亮、路由、四路状态、保存与回访通过；停止加范围 |
| 9:00–10:00 | 备份、重启和彩排、缓冲 | 如实标注现场生成/预生成/未实现；本机演示可完成 |

这是一项紧预算提案，不是十小时必达保证。若自由代码生成、外部搜索或全部市场模拟均要深入实现，需降低其他广度、增加时间或重排计划，不能靠文档把确认愿景抹去。

## 降级与未完成说明

先削 TXT、动效、图规模和每路主题广度；保留高亮与段落锚点、四路契约、组合状态和保存闭环。可以把活动层简化为分档颜色，把图谱预处理并明确标注。某路服务不可用时展示失败/重试，预生成结果只能标为预生成，不算现场路线已通过。若只完成部分路线，应明确报告“四路产品范围，当前完成 X/4”，不能改写为 SVG-only MVP 已完成。

若 1:30 高亮仍失败，优先修复或更换支持文件；若 3:15 路由未通过，暂停产物扩展解决上下文绑定；若 7:45 保存失败，停止加功能修复。任一降级不得把模拟正确性、出处真实性或真实检索替换成外观演示。

## 约三分钟演示

1. 展示左侧正常阅读、右侧整书网络，说明图谱处理覆盖与是否预生成。
2. 遇到不理解的段落，直接在原书选中并高亮；按最终确定方式启动辅助。
3. 展示路由到交互 UI 与概念图的组合、理由和独立进度。操作 UI 参数，解释教学假设；保存两份结果。
4. 用另两段预选示例快速展示图片与来源查找，各自说明现场/预生成状态及查找范围。
5. 缩小到活动/书签总览，回到原高亮，重开产物与交互状态；刷新验证保存。

## 验收清单

| 检查 | 通过标准 |
| --- | --- |
| 桌面 | 1440×900 / 1920×1080 下可读可选，原书与地图缩放独立 |
| 高亮输入 | 原书选文准确传入路由；跨行/跨页及重复引文不串段；刷新高亮恢复；无选文不拿节点替代 |
| 整书地图 | 完成清单后才标 complete；五个出处和三条关系抽查无错页/编造依据 |
| 路由 | 有单路与至少两路组合案例；无效路线拒绝；切换选区后旧结果仍指向旧选文 |
| 交互 UI | 实时生成路径可见，控件改变状态和图形；模型假设、范围及验证状态明确；边界参数无明显错误 |
| 图片 | 实际生成产物可保存/刷新重开，失败不假冒成功 |
| 概念图 | 由选文产生关系结构，标签可读，生成推断与书文区分 |
| 来源查找 | 按批准范围实际检索，可打开对应原文/链接并核对支持关系；空结果诚实显示 |
| 组合故障 | 一路超时不覆盖其他产物；重试不重复保存；调用遵守最终触发策略 |
| 保存与活动 | 产物始终关联高亮段落；地图未就绪仍可保存；书签恢复，事件不重复计量且不称理解度 |

当前没有实现、性能测量或通过测试的声明。执行后逐项记录实际结果，并区分产品意图、演示提案和已完成能力。
