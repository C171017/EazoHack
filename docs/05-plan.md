# 十小时范围、演示与验收

这是未来获准实现后的十小时计划，不是本轮已完成工作。假设一位熟悉 React 的开发者、可用模型账号/网络、一部预检过的短知识类书，本机桌面演示；多人并行不是预算前提。D01–D08 默认建议尚待确认。

## 建议范围

必须完成：一份可提取文本 PDF 的完整分块覆盖、左侧阅读、右侧概念图、有效出处跳转、明确请求一种图解解释、保存重开、简易活动色阶和手动空间书签。整书抽取结果允许有局限，但覆盖缺口和推断关系必须可见。

初始工程预算建议：选约 20–60 页的完整短书/小册子，首图约 15–30 个概念，每个概念只显示少量关键关系；这不是 API 限制或用户已确认范围。页数只用于筛选，最终以提取字符量、分块数和实测调用预算决定能否接纳。需要压缩节点数时保留全部分块覆盖，界面说明图谱是精选结构而非穷尽目录。

条件增量：UTF-8 TXT 适配、PDF 精确选区高亮。若无法同时完成，首版仅 PDF，通过节点出处卡片提供上下文；TXT 保留为下一个格式，不宣称支持。

本轮排除：OCR、复杂双栏/公式密集书、EPUB/DOCX、任意长书、3D、周期截图、自动生成、任意可执行小应用、图片生成、登录/协作/云同步。手动截图留在产品提案，未实现前不出现可用承诺。

## 10 小时分配

| 时间 | 工作 | 出口条件 / 失败处理 |
| --- | --- | --- |
| 0:00–0:30 | 确认核心决策、固定示例书、设输入规模和调用预算 | 未定产品核心则先讨论，不边做边猜；记录示例书来源与使用许可 |
| 0:30–1:30 | 最小阅读器、文字提取、锚点和模型请求预检 | 五个出处正确页定位，至少一个结构化返回可用；失败换排版简单的完整短书，仍失败转为明确标注的预处理演示 |
| 1:30–3:00 | 分块分析、合并、出处校验、覆盖进度 | 每块有状态，概念至少一处有效来源；模型失败可重试，演示缓存明确标为预生成 |
| 3:00–4:30 | 双栏与图谱、选概念/选出处、跳回原文 | 一个跨章导航路径可演示；此时固定图版本和布局 |
| 4:30–6:00 | 用户问题 → 图解数据 → 预览 → 保存 | 至少一种固定图解/步骤模板可用；失败保留上下文，不执行模型代码 |
| 6:00–7:00 | 本地恢复、书签、事件计数与缩小总览 | 刷新可重开产物；书签恢复视口/阅读位置；图例写明活动含义 |
| 7:00–8:00 | 串联、空态/错误/加载状态；有余量才加 TXT 或选区 | 新格式失败不得破坏 PDF 路径；停止新增核心功能 |
| 8:00–9:00 | 桌面尺寸与来源/持久化验收、修复 | 核心验收全部通过；未通过优先修闭环 |
| 9:00–10:00 | 缓存/备份、重启彩排、录屏或演示素材、缓冲 | 清楚区分现场生成和缓存；本机运行就绪，不把部署当额外零成本任务 |

## 降级顺序

先砍 TXT、精确矩形高亮和动效；保留准确页码+出处文本。再把图解收窄成一个步骤模板，活动层收窄成分档节点颜色。模型或网络失败可用同一书预生成并验证过的结果，但标注“预生成演示”，不宣称现场处理成功。若只能处理章节，应标明“章节原型，整书目标未完成”，不能用“整书已完成”包装。

不得削掉出处真实性、用户触发、保存关联与错误状态来换视觉效果。若 4:30 还没有来源跳转，停止产物花样；若 7:00 保存仍失败，停止新增格式。

## 约三分钟演示

1. 展示书籍和完整处理覆盖状态；说明是现场分析还是预生成结果。
2. 在右图选择一个概念，查看关系标签与出处，跳到左侧原文核对。
3. 请求“把这两个概念的区别分三步说明”，预览图解并切换步骤；指出这是生成解释。
4. 保存到当前概念，切换到另一章节，再缩小看活动色阶和书签。
5. 点击书签回访，重开保存产物；刷新后仍能找到，展示出处链没有丢失。

## 验收清单

| 检查 | 通过标准 |
| --- | --- |
| 双栏桌面 | 1440×900 与 1920×1080 下阅读/图谱可用，面板不遮住主要按钮；图缩放不改变书页缩放 |
| 整书覆盖 | 清单中所有分块完成才标 complete；遗漏、乱码、失败有可见提示 |
| 来源 | 人工抽查五个跨页/跨章出处，无错页；重复引文和未知锚点不假装精确定位 |
| 关系 | 抽查三条边可查看依据、方向与推断标签；无不存在端点/编造出处 |
| 生成控制 | 翻页、悬停、缩放不生成；一次明确请求才产生一次任务；超时/拒绝不覆盖保存结果 |
| 保存 | 保存后刷新，产物、概念关联、书签和位置恢复；模拟写入失败时明确显示未保存 |
| 活动 | 主动事件计数符合图例，恢复页面不重复计数；不标注掌握度或理解度 |
| 输入失败 | 扫描件/损坏文件/超范围输入明确拒绝或说明限制，保留已有书籍状态 |

实际执行时在此追加通过/失败与测量记录；当前没有代码、性能数据或测试结果。
