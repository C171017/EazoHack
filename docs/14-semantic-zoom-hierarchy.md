# 多层节点、语义缩放与按视口加载

更新：2026-09-05。状态：设计已确认，随后已获授权并完成首版实现、Gemini 层级生成与本地验证。详见 [实现与验证记录](15-semantic-zoom-implementation.md)。本文仍为设计契约；基线设备性能验收尚未完成。固定空间分页已被语义缩放替代，拖动自动缩放已移除。

## 目标与交互

整书地图不再同时显示所有节点。触控板双指捏合控制地图缩放；平移浏览视口。缩放跨越不同阈值时，地图在细节节点与更概括的聚合节点之间转换，每个缩放档位都有同时显示数量上限。缩放按钮和键盘操作应走同一套机制，原书阅读区缩放与地图独立。

- 放大：聚合节点展开为下一层子节点，逐层到达叶节点。
- 缩小：子节点逐渐缩小并向代表它们的较大聚合节点过渡；聚合节点具有有意义的概括标题和摘要，能够解释所含内容，不能只是没有语义的圆点或数量标记。
- 聚合节点的较大尺寸表示它代表一组内容，不表示更正确、更重要或 Y 轴位置更高；可显示所含叶节点数量。
- 只渲染当前视口内、当前细节层级的活动节点及受预算约束的关系。这里“活动”指当前可见集合，不是阅读活动热度。
- **取消拖动视图时的自动缩放。** 平移或旋转拖动、拖动结束、投影吸附、可见节点变化以及分块到达都不得触发自动 fit/zoom；拖动必须保留用户设定的缩放值。明确的用户缩放和 Reset view 仍可改变缩放。

阈值来回跨越时需要连续、可逆、可取消的过渡：子节点收拢到父节点的显示位置，反向操作则展开。以手势焦点保持视觉连续性，避免跳动。进入和退出阈值采用不同边界（滞回），防止微小手势导致反复切层；快速反向操作从当前过渡状态继续。切层不改变原始语义坐标。动画期间父子临时共存也计入总预算，不能为过渡挂载整层。减少动态效果模式使用即时替换或最低限度动效。

## 整书分析生成层级

分析书籍时，先保存完整的已接受叶节点集合，再自底向上形成多层概括。这里“完整”指保留本次分析接受的全部节点，不声称模型已穷尽书中所有概念，也不能因显示上限截掉叶节点。

1. 提取有出处的叶节点、概念身份、各次出现及有类型的关系；沿用原文、锚点、审核和 unknown 规则。
2. 应用先确定并锁定共享 XYZ 坐标。用该空间中的邻近节点提出分组候选，由 LM 判断能否形成忠实、有意义的概括。不能按每次屏幕投影重新分组，也不能仅因投影后重叠就宣称内容相同。
3. LM 为合适的相邻节点生成上一层聚合节点，记录标题、摘要、直接子节点、来源覆盖和分组理由。空间接近是候选依据，语义是否可以合理概括仍须核验；矛盾观点不能被摘要抹平。
4. 对上一层重复同一过程，直到形成可在总览预算内浏览的顶层集合。LM 自动提出适合这本书的层数，不为所有书写死相同深度；小书可以只有叶层，各分支也可具有不同深度。
5. 应用校验层级、引用和预算；不合格时要求重新分组或补层。有界重试失败则明确标记层级未就绪，保留上一份可用版本，不发布不合格层级。

LM 的层数判断必须结合应用提供的节点预算和分组约束；LM 不能凭文字判断证明 M1/M2 或 Windows 设备性能。最终预算由实际测量确定，并由应用强制执行。不能为了减少节点而生成没有依据的宽泛概括。

**聚合层级与 X reasoningDepth / Y generality 是两个独立维度。** 叶节点表示显示层级的最细单位，其语义本身可以是例子、概念或原则，不要求所有叶节点都处于 X=0 或 Y=0。聚合层数可以变化，不对应固定 0–4 的语义层级。聚合显示位置是由应用在子节点中选择的稳定导航代表；同时保留完整子树范围，应标明为聚合；不能冒充新的精确出处坐标，不能把跨章概念身份压成虚假的单次出现。

## 数据与校验契约

以下是逻辑字段要求，具体 schema 和存储切分方式由实现确定。

| 对象 | 必须保存的内容 |
| --- | --- |
| 层级清单 | graphVersion、hierarchyVersion、来源/提取版本、生成模型与提示版本、顶层 ID、实际深度、构建状态、分块索引、预算配置版本 |
| 叶节点 | 稳定 ID、原有 identity/occurrence 与 SourceAnchor、真实语义坐标、父级引用；未知坐标保持未知 |
| 聚合节点 | 稳定 ID、标题/摘要、直接子 ID、父 ID、聚合层级、后代叶节点数量、证据引用、分组理由、子树空间包围范围、派生显示位置 |
| 可加载分块 | 版本、层级/子树、范围、节点和关系引用、加载状态；可独立请求、缓存与校验 |
| 显示预算 | 各缩放档位节点/边/标签上限、进入/退出阈值、过渡并存预算、缓存和预取限额 |

同一 hierarchyVersion 内，叶节点在导航层级中只属于一个直接父组；其他多对多含义由语义关系表示，不复制叶节点。校验须拒绝环、悬空子引用、重复成员、混合版本、错误数量和不覆盖子树的范围；确保每个已接受叶节点都有顶层可达路径。单叶树无需伪造父节点。无法定位的节点保留在可访问列表中，不放在原点凑数。

聚合之间的边是底层关系的派生汇总，必须保留类型、方向、数量和原关系引用；支持与反驳不能合成一个不明方向的结论。父子包含关系与书中论证关系明确区分。下钻后能回到实际节点、关系证据和原文。

## 加载、选择与渲染预算

先加载小型层级清单及顶层概括，按当前视口、投影和缩放档位加载所需子树；邻近区域可有界预取。屏幕外节点不挂载为隐藏 DOM/SVG；节点裁剪必须同时减少标签碰撞、边计算和命中检测的工作。使用空间/层级索引查找候选，避免每帧扫描、投影或布局全书。数据缓存与实际渲染集合分开，浏览器缓存需要容量限制和淘汰机制。

某档位超出上限时，使用覆盖这些内容的更高层父节点代替部分细节，形成不重复覆盖的可见集合；不能随机删掉超限节点，让内容看起来不存在。单个父组也可能非常大，所以下钻同样受预算约束。边与标签分别限额，必要时省略部分标签/关系并提供查看入口；不隐藏节点可达性。

用户选中节点被聚合或移出视口时，保留选择和出处面板，以可见父节点表示包含关系；不强行维持屏幕外节点渲染。从搜索、关系或书签前往叶节点时，加载祖先路径并展开到可访问的层级。完整列表采用按需/虚拟化呈现，避免把画布节省的成本转移到全量 DOM 列表。

异步分块晚到不得重置相机或覆盖新手势；旧版本/过期视口请求可取消或忽略。子树未就绪时保留父节点及加载/失败/重试状态，不出现空洞；切层应复用预处理层级，不在每次手势中调用 LM。接受叶图但层级尚未完成时分别报告状态，原文阅读和高亮辅助仍可使用。

## 设备目标与验收

最低性能覆盖目标为 **MacBook Air M1、M2，以及同档次主流 Windows 笔记本，包括仅集成显卡的设备**。有独立显卡的 Windows 笔记本也应运行良好，但不以独显为前提。这是目标设备范围，不是已经通过的硬件兼容或性能结论；内存、系统、浏览器、分辨率和具体 Windows 机型须在测量中记录。

| 场景 | 验收要求 |
| --- | --- |
| 连续捏合、平移、旋转 | 手势响应顺畅；拖动及结束不改变 zoom；无由加载/聚合触发的自动缩放 |
| 阈值反复跨越、快速反向 | 无闪烁和不可取消动画；焦点连续；父子临时共存也不超预算 |
| 密集区域与超大子树 | 节点、边、标签始终受限；通过聚合保留所有内容的下钻路径 |
| 冷启动与长时间探索 | 按需加载；记录首个可交互总览时间、请求量、内存峰值及缓存淘汰，避免随访问区域无限增长 |
| 真实性与恢复 | 每个叶节点可达、来源不变；无环/重复/悬空引用；慢请求、失败、版本切换及书签恢复不串数据 |
| 无障碍与投影 | 减少动态效果、键盘及列表可用；自由 3D 和三个投影使用同一层级与出处 |

后续以代表性整书、大型密集图和不均匀子树测量帧时间（含 p95）、交互延迟、主线程长任务和内存；同时开着阅读器测量上述基线设备。**首版缩放阈值、数量、动画和缓存预算已在实现记录中定值；基线设备的帧时间/延迟及内存通过值仍待性能验收确定**，并须记录实测结果。不能把旧的 24 节点分页、80 节点保护或模型建议直接当成合格性能证据。

## 实施衔接与剩余验收

首版已依此顺序完成，剩余重点为基线设备验收与调参（详情见实现记录）：定义并校验层级 schema → 在整书分析中增加自底向上构建/审核/恢复阶段 → 生成分块与索引 → 接入按视口加载和显示预算 → 捏合缩放、阈值过渡与取消拖动自动缩放 → 基线设备测量并调参。已有平面图快照需显式重建层级或继续标记为旧模式；不得声称现有分析结果已经包含这些字段。
